# WhatsApp Housekeeping Bot 🧹📲

A WhatsApp automation bot built with Python and integrated with Google Sheets to manage housekeeping requests for a hotel.

## Features
- Automatically responds to WhatsApp messages from housekeeping staff
- Stores and updates request data in Google Sheets
- State-based conversation handling

## Technologies
- Python 3
- Google Sheets API
- Make (integration platform)
- WhatsApp (via webhook or Make scenario)

## How to Use
1. Clone this repo
2. Create your Google Sheets API credentials
3. Add your credentials to the environment
4. Run the bot: `python main.py`

> Integrate with WhatsApp using Make or Twilio for webhook handling
